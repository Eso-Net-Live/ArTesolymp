Документація ArTesolymp

Повний посібник: як проходити тести, створювати їх, додавати відео, імпортувати/експортувати JSON та аналізувати результати.

1. Швидкий старт

  1. Натисніть «Вхід / Реєстрація» у верхньому правому куті та створіть акаунт (учня або учителя).
  2. Учень: натисніть «Ввести код доступу» і введіть код, який дав учитель — або оберіть публічну олімпіаду з каталогу.
  3. Учитель: натисніть «Конструктор тестів» → оберіть спосіб створення → опублікуйте → роздайте код доступу учням.
  4. Результати учнів дивіться у Профілі → «Переглянути результати учнів».

2. Для учня

  • Код доступу — введіть у вікні «Ввести код доступу». Приватні тести доступні лише за кодом; публічні видно в каталозі.
  • Пароль тесту — якщо вчитель його встановив, система попросить його перед стартом.
  • Розділи (вкладки) — питання згруповані за розділами; перемикайтеся вкладками та номерами питань («пігулками») над питанням.
  • Автозбереження — відповіді зберігаються автоматично; можна повернутися до питання й змінити відповідь до завершення.
  • Дедлайн — після закінчення терміну тест закривається. Повторна спроба можлива лише якщо вчитель її дозволив.
  • Завершення — кнопка «Завершити» покаже попередження про питання без відповіді; після підтвердження відповіді відправляються на перевірку.
  • Відео в питаннях — відтворюється прямо на сторінці (YouTube, Vimeo, Google Drive або файл).
  • Історія — усі ваші проходження зберігаються в Профілі; зайве можна прибрати з історії.

3. Акаунт учителя

Під час реєстрації оберіть роль «Учитель». Запит підтверджує адміністратор платформи; до цього часу акаунт працює як учнівський. Після підтвердження стають доступні конструктор, експорт JSON і перегляд результатів учнів.

4. Створення тесту: три способи

Після натискання «Конструктор тестів» відкривається вибір:

З нуля

Порожній конструктор. Задайте назву, код, дедлайн, доступ, розділи, додайте питання.

Шаблони

Обираєте заготовку → вона відкривається в конструкторі, де ви змінюєте тексти, відповіді й бали.

Завантажити з JSON

Файл або вставлений текст. Система перевіряє дані та виправляє помилки значеннями за замовчуванням.

Параметри тесту

  • Код доступу — 4–40 символів (латиниця, цифри, _ -). Порожній → генерується автоматично.
  • Дедлайн — дата й час закриття. Порожній → +1 рік.
  • Доступ — приватний (лише за кодом) або публічний (у каталозі).
  • Режим — «Тест» або «Олімпіада»; Повторне проходження — дозволити чи ні.
  • Пароль — необов'язково, 4–128 символів; на сервері зберігається лише хеш.
  • Прев'ю — кнопка «Перевірити тест» дозволяє пройти тест перед публікацією.
  • Тест, який уже проходили, редагувати не можна — створіть копію у Профілі й змінюйте її (так історія відповідей не псується).

6. Фото, відео та YouTube

До кожного питання можна додати одне медіа. У конструкторі є поле посилання та кнопки «Фото» і «Відео»:

  • YouTube — вставте будь-яке посилання: youtube.com/watch?v=…, youtu.be/…, /shorts/…. Можна вказати час старту: ?t=90 або ?t=1m30s.
  • Vimeo — посилання vimeo.com/123456789.
  • Пряме відео — посилання на файл .mp4, .webm, .ogg, .mov.
  • Google Drive — посилання drive.google.com/file/d/… (файл має бути відкритий «усім, хто має посилання»).
  • Завантаження відео-файлу (кнопка «Відео», до 20 МБ) — файл зберігається на Google Drive власника скрипта в папці ArTesolymp_videos, а в питанні лишається лише посилання. Для більших відео використовуйте YouTube.
  • Фото — посилання або файл; великі зображення автоматично стискаються.

У JSON усі ці варіанти записуються в одне поле urlOrFile.

7. Завдання з кодом

  • Учасник пише код, який читає input() і виводить print(). Ви задаєте еталонний код — відповіді порівнюються з його виводом.
  • Формат входу: i<мін макс> — ціле, f<мін макс> — дробове, s<мін макс> — рядок довжини від…до, s[1] — слово зі списку «fixJsonWords», m<…> — змішане. Новий рядок формату = новий рядок входу. Приклад: i<1 100>.
  • Тип входу (typeInput): int (числа), fix string (конкретні слова), string (випадкові рядки), mixing (суміш).
  • Спеціальні тести (specHideTest) — власні набори входу, розділені рядком ---. Решта до TestsCount генерується за форматом.
  • Режими балів (partialScore): true — частково за кількість пройдених тестів; false — все або нічого; null — перевіряє вчитель.
  • Ліміти: Memory (МБ, 1–900), Timeout (мс, 100–15000), MaximumTest — скільки разів учень може запускати перевірку, TestsCount — приховані тести (1–100).

8. Формат JSON

Файл можна написати вручну, згенерувати або отримати експортом (розділ 9). Дозволені коментарі // … та /* … */, а також зайві коми. Якщо параметр неправильний або відсутній — підставляється значення за замовчуванням (звіт про зміни показується під час імпорту).

9. Експорт тесту в JSON

                        
У Профілі, у списку «Мої створені тести й олімпіади», поруч із кнопкою «Редагувати» є кнопка «Завантажити JSON». Файл містить усе, окрім пароля (на сервері він зберігається лише як хеш — у файл потрапляє "password": null). Такий файл можна імпортувати на іншому акаунті, зберігати як резервну копію або редагувати вручну.

                        
Увага: файл містить правильні відповіді та еталонний код — не передавайте його учням.

                    


                    

                        
10. Результати учнів і CSV

                        
    
                            
  • Профіль → «Переглянути результати учнів» → оберіть тест або олімпіаду зі списку.
    • 
                            
  • Таблиця: Місце · Користувач · питання 1…N · Результат. Колір клітинки — відсоток набраних балів (червоний → жовтий → зелений). Наведіть курсор, щоб побачити «бали / максимум» та назву питання.
    • 
                            
  • Сортування: за місцем (зростання/спадання) та за іменем (А→Я / Я→А). Однакові бали ділять одне місце.
    • 
                            
  • Краща спроба / Усі спроби — якщо дозволено повторне проходження.
    • 
                            
  • У відсотках — перемикач відображення. Внизу — рядок «Середнє», зверху — статистика (учасники, середній, найвищий, найнижчий, медіана, успішність).
    • 
                            
  • «Завантажити CSV» — один клік; файл враховує поточне сортування й пошук, роздільник «;», UTF-8 — відкривається в Excel/Google Sheets.
    • 
                            
  • Щоб перевірити відповіді й виставити бали вручну — розділ профілю «Результати учасників» → «Відповіді / оцінювання».

11. Часті питання

                        

                            
Відео не відтворюється.
YouTube: перевірте, що власник дозволив вбудовування. Drive: відкрийте доступ «усім, хто має посилання». Файл: використовуйте MP4 (H.264).

                            
Імпорт JSON видає помилку.
Найчастіше — пропущена лапка/дужка або порожній масив questions. Повідомлення покаже причину. Інші неточності виправляються автоматично.

                            
Чому дедлайн замінився?
Дата не існує (наприклад, 31-09) або вже минула. Перевірте формат ДД-ММ-РРРРTГГ:ХХ.

                            
Не можу відредагувати тест.
Його вже проходили. Створіть копію в Профілі та редагуйте її.

                            
У результатах 0 за текстове питання.
Воно ще не оцінене вчителем. Оцініть у Профілі й оновіть таблицю.
